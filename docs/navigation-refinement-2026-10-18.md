# ヘッダー整理・トップ改善（2026-10-18）

- ヘッダーをCollection（Brands / Products / Lookbook）、About（About ReStandard / Vision / Location）、News、Contactに分類。Online StoreとJA/ENは右の独立領域へ配置。
- 旧ページの言語ボタン用スタイルが商品ページと異なる寸法を指定していた。ヘッダーのクラスを既存Bootstrap/Editorial用ルールから分離し、書体・寸法・左右ガターを共通化。ロゴ、中央メニュー、右の操作領域を同じグリッドに配置。
- モバイルではJA/ENを常時表示。メニューを開くと分類別リンクを一覧。分類はnative detailsを利用し、JavaScript無効時もリンクへアクセス可能。Esc、外側クリック、画面幅切り替え、キーボード操作を確認。
- トップは白い余白を中心にし、細めの明朝系見出しと短い会社紹介に調整。操作部を写真の下へ移動。自動切り替えは6.5秒から5秒へ。停止・再開、スワイプ、動きを減らす設定を維持。
- Pink（BASE ID 124700633）は登録画像の3枚目、赤系チェックのスカートを着た写真に変更。提案スカートはBlackstewart（124702404）へ揃えた。BASEの商品情報や画像内容は変更していない。

検証：全112ページのヘッダーを含め154表示で座標・書体を比較。320 / 375 / 768 / 1000 / 1024 / 1440 / 1920 / 2560pxでページ間の差0.15px以内を確認。分類メニューの開閉、PCキーボード操作、スマートフォンの移動、英語切り替え、固定位置、JS無効時のリンクも確認。商品データの18テスト合格。

メンテナンス：共通ヘッダーはcatalog/site-shell.cjs、見た目はcss/site-shell.css、動作はjs/editorial.jsに集約。ビルド時に全静的ページへ適用。test:headerでページ間の座標差を検出できる。

## カーソルの追加統一

個別ページに埋め込まれていた丸いカーソルをcss/cursor.cssへ集約。全静的ページ、商品・ブランド・カテゴリーの動的ページ、今後の記事テンプレートへ適用。PCのリンク、ボタン、分類メニューを同じ丸いカーソルにし、拡大（zoom-in）、ドラッグ中（grabbing）、入力（text）、無効な操作（not-allowed）の意味は保持。タッチ端末ではカスタムカーソルを使わない。外部iframe内部は外部サービス自身が制御する。
